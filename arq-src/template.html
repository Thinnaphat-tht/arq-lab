    คอลัมน์ที่สว่างขึ้นคือโหมดที่เลือกอยู่ในแล็บ

    สรุปให้จำ: Stop-and-Wait คือกรณีพิเศษของ Go-Back-N ที่ window = 1 และใช้เลขลำดับแค่ 0 กับ 1  ·  GBN มองเฟรมเป็น "กลุ่ม" ส่วน SR มองเฟรมเป็น "รายตัว"

    หลุมพรางข้อสอบ

    1. ขนาด window ของ GBN กับ SR ไม่เหมือนกัน

    GBN: sender = 2^m − 1 (เลขคี่เสมอ), receiver = 1 เสมอ
    SR: sender = receiver = 2^(m−1) (เลขคู่เสมอ)

    2. เลข ACK คือ "เฟรมที่รอถัดไป"

    ACK 1 แปลว่าได้ frame 0 แล้ว กำลังรอ frame 1 ไม่ใช่ "ได้ frame 1" และใน GBN ACK เป็นแบบสะสม เช่น ACK 4 = ได้ frame 0, 1, 2, 3 ครบแล้ว

    3. "ACK หาย" กับ "เฟรมหาย" ให้ผลต่างกัน

    เฟรมหาย: ผู้รับไม่รู้เรื่อง ไม่ตอบอะไร มีแต่ timeout ที่ช่วยได้
    ACK หาย/ช้า: ข้อมูลถึงแล้ว ผู้รับต้องทิ้งเฟรมซ้ำแต่ยังต้องตอบ ACK ใน GBN ถ้า ACK ตัวถัดไปมาทัน ก็ไม่ต้องส่งใหม่เลย

    4. เลขลำดับต้องวนเป็นวง

    ส่ง 20 เฟรมด้วย m = 4 ได้ 0, 1, …, 14, 15, 0, 1, 2, 3 ไม่ใช่ 16, 17, 18, 19

    5. อย่าสลับ REJ กับ SREJ

    REJ = NAK ของ Go-Back-N · SREJ = NAK ของ Selective Repeat
    RNR ไม่ใช่ error แต่เป็น flow control (ผู้รับบอกว่า "ได้แล้วนะ แต่ขอพักก่อน")

    เครื่องคิดเลข ใส่ตัวเลขแล้วดูทีละขั้น

    เวลารวม: Stop-and-Wait เทียบ Go-Back-N
